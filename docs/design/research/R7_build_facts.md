## Constraints the design must respect
1. The server has NO NVIDIA GPU (AMD Radeon 780M iGPU only): Chatterbox runs on CPU at about 4.1 s of compute per second of audio (a 12-minute episode is about 50 min), the final render about 2.0 min per output minute; `h264_nvenc` cannot be used. Voice and render both need the heavy-job lock and must be split into jobs under about 30 min.
2. `agy` on the server (1.5.9, has `--settings` and `--input-format`) is NOT signed in. The owner must sign in once on the server before the script button or the draft agent can work there; an `agy.exe` process (pid 4908) has been waiting since 16:18.
3. The server `.venv` contains only pip, and PyMuPDF is missing from the comic `.venv`; the app has never run on the server. Installing packages needs the owner's yes (rule: no installs). `import bti.editor.app` needs `pymupdf` at import (`app.py:27` -> `bti.library.catalogue`).
4. The server copy is ahead of the Mac for `bti/proc.py`, `antigravity.py`, `clips.py`, `editor/__main__.py` (the stash), and the deploy script mirrors folders with `/MIR`: the stash must be restored (applied by the owner, not by me) before the next deploy or the Windows fixes are lost.
5. Long prompts must go through stdin (`--input-format stream-json`) on Windows; the drafting prompt cannot be a `-p` argument. The registry summary is about 31-37 KB; the design should send a compact, per-intent subset or put the registry in a workspace file.
6. An agentic `agy` run needs a different guard from `complete()`: the "no tools, one turn, no files written" checks must be replaced by a workspace copy, a fixed output path, a shape check (`proposals.shape_problem`) and a check that nothing was written outside; keep the env whitelist (add Windows variables), process-tree kill, one run at a time, time limit. The real stream-json event shapes are unverified.
7. A proposal is a full storyboard document, matched by id; `apply` never touches locked items and sets `source:"agent"`; it does not re-tile shots, does not delete the proposal file, and only flags stale ones (`base_rev` vs `compute_rev`). The agent's document must already tile the timeline and use valid slot/param values; incomplete items are warnings, approval refuses them.
8. `timing.json` needs only `words[{w,s,e?}]`, `beats[{start,end,w0,w1,...}]`, `chapters[{name,start,end}]`, `duration`; word times for a new voice must come from forced alignment (faster-whisper is not on the server, runs on the Mac in the benchmark) or from the even spread inside each sentence chunk (exact only at sentence boundaries). The engine wants `audio/mix.m4a`-like AAC 48 kHz stereo at about -15 LUFS.
